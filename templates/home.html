Ontology Generator

This tool allows you to create a seed ontology from GOV.UK content in a given domain using LLMs.

Steps to creating an Ontology

  • Create a content domain by inserting all URLs of the content you want your Ontology to be based on.
  • Go to Create Ontology, select domain, and add prompt and define settings.
  • If you want to review the generated ontologies and domains go to the Review Ontologies and Review Domains.
